# Dental Payment Tech Site

Create a modern, clean, responsive landing page for "HealthPaymentTech.com" designed specifically for modern dental practices. Follow the exact layout, section order, color palette, and visual tone provided in the specification below.

---

### 🎨 DESIGN & STYLING GUIDELINES

- Domain: HealthPaymentTech.com

- Color Palette:

  - Primary Navy Blue: #0b2545 / #0e2a47

  - Accent Green: #2ba84a / #34a853

  - Background Light Mint / Soft Gray: #f2f8f5 / #f8faf9

  - White: #ffffff

- Typography: Clean sans-serif font (e.g., Inter, Montserrat, or Outfit) with bold geometric headings. Include handwritten-style accents in green for secondary slogans (e.g., Caveat or Gochi Hand style font).

- Style/Vibe: Professional, trustworthy, modern healthcare-tech layout with subtle shadows, rounded cards, and vibrant green iconography inside circular badges.
